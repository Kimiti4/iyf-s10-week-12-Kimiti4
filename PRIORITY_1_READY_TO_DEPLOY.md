## 🎨 **SCORING SYSTEM**

### Formula
```
Score = (Helpfulness × 0.30) +
        (Reliability × 0.25) +
        (Quality × 0.25) +
        (Community × 0.20)
```

### Example
```
User Alice (helps 3 people):
  Event 1: +10 points
  Event 2: +10 points
  Event 3: +10 points
  ↓
  Total: 30 points
  Badge: 🥉 Bronze Helper
```

### Badge Tiers
```
🥉 Bronze:    0-40   (Getting started)
🥈 Silver:   40-60   (Making impact)
🏆 Gold:     60-75   (Community leader)
💎 Platinum: 75-90   (Legendary)
👑 Legend:   90+     (Elite member)
```
